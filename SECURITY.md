# Security Policy

Use the incident fixtures only against synthetic or explicitly authorized environments. They describe detection conditions and do not contain weaponized payloads.

Never commit credentials, raw production prompts, tool results, personal data or customer incident evidence. Hashing predictable identifiers alone may not provide anonymity; use an approved keyed pseudonymization process where correlation and privacy requirements demand it.

Report vulnerabilities using GitHub private vulnerability reporting when available. Include the affected version, synthetic reproduction, impact and suggested mitigation. Avoid publishing details that could cause immediate harm.
